# Day 2 - Flask Fundamentals & Web Application Basics

## Topics Covered

- Introduction to Flask
- Creating a Flask Application
- Routes and URL Mapping
- Browser to Server Communication
- HTTP Requests and Responses
- Running Flask Applications
- Understanding localhost and Port 5000
- Basic Web Application Workflow

Learned how Flask receives browser requests, processes them through routes, and returns responses to users.

## Workflows Learned

Browser → HTTP Request → Flask Route → Function Execution → HTTP Response → Browser

Built a strong understanding of Flask fundamentals and web application architecture, creating a foundation for future web security topics.
