# 🛡️ Cybersecurity Learning Journey

Welcome to my Cybersecurity Learning Journey.

This repository documents my step-by-step learning process in cybersecurity, web development, and web application security. Each day contains notes, concepts, workflows, practical exercises, reports, and learning outcomes.

The goal is not only to learn cybersecurity tools, but also to understand how web applications work internally before learning how they are attacked and secured.

---

# 🎯 Learning Goals

By the end of this journey, I aim to understand:

- Linux Fundamentals
- Networking Basics
- Web Development Fundamentals
- Flask Web Applications
- Authentication & Authorization
- Session & Cookie Security
- OWASP Top 10
- SQL Injection
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Secure Coding Practices
- Web Application Security Testing
