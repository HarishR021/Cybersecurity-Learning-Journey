# 🛡️ Cybersecurity Learning Journey

Welcome to my Cybersecurity Learning Journey.

This repository documents my step-by-step learning process in cybersecurity, web development, and web application security. Each day contains notes, concepts, workflows, practical exercises, reports, handbooks, and learning outcomes.

The goal is not only to learn cybersecurity tools but also to understand how web applications work internally before learning how they are attacked, tested, and secured.

By the end of this journey, I aim to understand:
